# Ambit Unified Project

This is the unified repository for the Ambit application, housing both the React + Vite frontend and the Next.js backend.

## Structure

- `frontend/`: The React + Vite frontend.
- `backend/`: The Next.js API server using Prisma and PostgreSQL.

## Getting Started

To get started, follow these simple steps:

1. Install all dependencies for both frontend and backend:
   ```bash
   npm install
   ```

2. Start both the Vite frontend and Next.js backend simultaneously:
   ```bash
   npm run dev
   ```

The frontend will run on http://localhost:5173, and backend API routes will run on http://localhost:3000.
